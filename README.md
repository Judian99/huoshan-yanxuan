# 火山严选 · 手帐食谱本

一个私人菜谱应用，单页滚动的手帐式信息架构：从今日餐单一路往下翻到月历，靠浮动索引坞在四个区块间跳转。纸张视觉语言，无外部依赖。

## 在线地址（GitHub Pages）

- 入口：`https://judian99.github.io/huoshan-yanxuan/`（自动进入手帐食谱本）
- 直达：`https://judian99.github.io/huoshan-yanxuan/demo-b/index.html`

桌面也可直接双击根目录 `index.html`（会跳转到 `demo-b/index.html`）。建议把窗口收窄到 480px 以内模拟手机。

## 已实现的功能

- **菜谱**：内置 12 道示例；按菜名/食材搜索、按时段筛选、详情（食材/步骤/备注）、写新菜谱（名称、照片、适合餐次、用时、动态食材与步骤行、备注、必填校验）。
- **点菜**：五时段；当天按当前时间预选时段；未来日期必须先选餐次；过去日期只读；可直接点某个餐格进入对应餐次；点菜支持撤销。
- **转盘**：SVG 转盘、按时段筛选、可避开当天已点的菜、最多 8 段候选、旋转结果票据、结果可加进指定餐次。
- **日历**：月切换、红点、今天圆环、选中日、回到今天；选中日期驱动全站日期；支持跨月/历史翻看。
- **复制**：把某天菜单复制到之后 7 天中的任意一天，可勾选餐次，支持撤销。
- **数据持久化（本地）**：菜谱、餐单、照片通过 IndexedDB 保存，刷新/重开不丢；照片先压缩（长边 ≤1000px、JPEG 0.72）再入库。
- **离线与安装**：Service Worker 预缓存外壳，可加到 iPhone 主屏幕当独立 App，联网打开一次后即可离线使用。
- **备份**：底部「导出备份 / 导入恢复」，导出为含全部菜谱（照片 base64 内嵌）与餐单的单个 JSON。
- **反馈与可达性**：底部印章 Toast（带撤销）、弹层可叠层、键盘焦点管理、`prefers-reduced-motion` 支持。

## 工程说明

```
index.html            入口落地页，自动跳转到 demo-b
shared/
  base.css            设计令牌、纸张纹理、通用控件、弹层/转盘/日历
  data.js             示例菜谱、相对日期菜单、五时段与内存操作（emitChange 触发持久化）
  wheel.js            SVG 转盘绘制与旋转
  kit.js              日期条、餐次选择、选菜、详情、表单（含图片压缩入库）、复制、Toast
  store.js            IndexedDB 持久化、图片压缩、导出/导入、storage.persist
demo-b/               手帐食谱本（含 manifest.webmanifest / sw.js / icons，可装成 PWA）
tools/gen-icons.js    纯 Node 的图标生成脚本
```

全部使用 classic script + 相对路径，不依赖外网字体、图片或接口，无构建步骤。

## iPhone 安装与数据持久化

数据（菜谱、餐单、照片）只存在用户自己的手机里，服务器只托管应用外壳，不接触任何私人数据。

**为什么不能直接打开 HTML：** iPhone 上的 Safari 不能直接打开本地 `file://` 的 HTML（Files 预览不执行 JavaScript、不加载外部样式），必须通过 HTTPS 地址访问。

**装到主屏幕：**

1. 用 Safari 打开在线地址（必须是 Safari，第三方浏览器在 iOS 上能力受限）。
2. 点底部「分享」→「添加到主屏幕」（iOS 26 若出现「打开为 Web App」开关，请打开）→「添加」。
3. 从主屏幕图标进入即为无地址栏的独立 App。

**离线与数据：**

- 首次需**联网打开一次**，让 Service Worker 缓存外壳；之后飞行模式也能完整使用。
- 普通 Safari 网页对 IndexedDB/localStorage 有「7 天不互动即清理」策略；**加到主屏幕的 Web App 豁免该清理**，iOS 17+ 还会自动授予持久化存储（应用启动也会主动调用 `navigator.storage.persist()`）。
- 兜底：定期用底部「导出备份」保存 JSON 到「文件」或 iCloud；清数据或换手机后用「导入恢复」还原。

**已知边界：** 用户手动「清理网站数据」、卸载主屏幕 App 仍会删除本地数据，因此需要定期导出备份。需要跨设备同步则要上云端（另立方案）。

## 本地预览

仓库根目录执行 `python3 -m http.server 8000`，浏览器访问 `http://localhost:8000/`（Service Worker 完整能力需 HTTPS，localhost 除外）。
